How can we help?

Help inside MathSheet

Press F1. Every feature has a topic and a lesson, with search and example sheets.

Explain an error

Right-click a red line and choose Explain this error for the cause and the fix.

E-mail us

sheetwiseengllc@gmail.com
We usually reply within two working days.

Common questions

Where is my license key?

On the Lemon Squeezy order page and in the receipt e-mail. Can't find it? E-mail us with the address you bought with.

How do I activate it?

See activating a license. It needs the internet once.

I have a new computer

E-mail us with your order number and we will move your license to the new computer.

My trial ended - is my work lost?

No. MathSheet keeps opening and printing your worksheets. Enter a license key to edit and save again.

Windows warned me when I started the installer

SmartScreen can warn about new programs. Click More info, check that it names MathSheet, then Run anyway. If anything looks wrong, e-mail us before running it.

Can I open worksheets from another program?

Yes, .xmcd files: File › Import worksheet (.xmcd). See import for what comes across.

When you e-mail about a problem

Please include the MathSheet version (Help › About), what you did, and if possible the worksheet file.
