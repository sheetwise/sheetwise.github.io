Features

Everything below is included in one licence. No add-ons to buy.

Equations and units

  • Type equations in natural notation; place them anywhere on the sheet
  • Definitions with :=, answers with =, global definitions
  • SI, US and CGS units, prefixes from pico to tera, °C / °F and decibels
  • Your own units and functions
  • Vectors, matrices, ranges, complex numbers
  • Sums and products, derivatives and integrals

Graphs

  • X-Y and polar plots, several traces per graph
  • Bode plots with crossover and phase margin
  • 3D surfaces, contours, bars, curves and vector fields
  • Zoom, trace cursor, markers, own formats and defaults
  • Animation, saved as a video

Solving

Roots of functions and polynomials, solve blocks with conditions, closest fit, maximize and minimize, solve blocks used as functions.

Symbolic math

Simplify, expand, factor, series, partial fractions, limits, Laplace, Fourier and z-transforms and their inverses.

Programs

Small programs inside a definition: if / otherwise, for and while loops, error handling.

Reports

Rich text, headers and footers, page setup, print preview, PDF, web page and Word export.

Excel

Copy a sheet to Excel with live formulas, or save an Excel workbook with the graphs already drawn.

Import

Open .xmcd worksheets from the older program you may already have, with plots rebuilt live.

Pictures and data

Pictures from files or the clipboard, pictures made from matrices, data tables pasted from Excel, attached files.

Training built in

Help with lessons, an error explainer, a user manual written as a course, and example sheets for every feature.

System requirements

Windows 10 or Windows 11 (64-bit). Uses the Microsoft Edge WebView2 Runtime that comes with Windows. An internet connection is needed only once, to activate a licence key.
