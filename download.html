Download MathSheet for Windows

Windows 10 or 11, 64-bit. Version 1.35.

How to install

  1. Download the file and open it (it is in your Downloads folder).
  2. Read the licence agreement and click I agree.
  3. MathSheet is added to the Start menu. Double-clicking a .msheet file opens it in MathSheet.
  4. To begin, open Help > Example sheets or the user manual.

Already bought it?

Open MathSheet, choose Help › Licence › Enter licence key and paste the key from your e-mail. You do not need to reinstall.

Uninstall

Open Windows Settings > Apps, find MathSheet and click Uninstall. Your worksheet files are not deleted.
