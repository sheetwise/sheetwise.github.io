Install

  1. Download MathSheet-Setup-1.41.exe with the button above and open it from your Downloads folder.
  2. Check the publisher. The installer is digitally signed by Sheetwise Engineering LLC. Whenever Windows shows a publisher name for the file, it must be exactly that.
  3. Read the license agreement, tick I accept and click Install. MathSheet installs for your Windows user only; no administrator rights are needed.
  4. Start MathSheet from the Start menu. Double-clicking a .msheet file also opens it.
  5. New to MathSheet? Open Help › Example sheets or the user manual.

Check the download (optional)

Every release lists the SHA-256 checksum of its installer. In Windows PowerShell, run:

Get-FileHash "$env:USERPROFILE\Downloads\MathSheet-Setup-1.41.exe" -Algorithm SHA256

The Hash it prints must match: published with each release

You can also right-click the file, choose Properties › Digital Signatures and check that the signer is Sheetwise Engineering LLC.

If Windows warns you about the file: please do not override the warning. Windows Defender SmartScreen can show a message for software it has not seen often yet, even when the file is signed. If the publisher is missing or is not Sheetwise Engineering LLC, or the checksum does not match, delete the file and download it again from this page. Still unsure? E-mail sheetwiseengllc@gmail.com and we will help you check it.

After you sign up: activate your license

  1. Find the license key on the order page or in the receipt e-mail from Lemon Squeezy.
  2. Make sure the computer is online (needed this one time).
  3. In MathSheet choose Help › Licence › Enter licence key, paste the whole key and confirm.
  4. MathSheet is now licensed on this computer and works offline from then on.

The key works on one computer. Replacing your computer? E-mail sheetwiseengllc@gmail.com with your order number and we will move it.

Uninstall

Open Windows Settings › Apps, find MathSheet and choose Uninstall. Your worksheet files are not deleted.
